# SIS112 - Programación I

Repositorio base de la materia Programación I.

En este repositorio se publicarán los ejercicios y actividades prácticas desarrolladas durante la materia.

## Estructura

Los ejercicios se encuentran dentro de la carpeta `ejercicios/`.

```text
ejercicios/
├── 01-calculadora/
├── 02-...
└── ...
```
Cada ejercicio puede contener una estructura similar a:

```text
ejercicio/
├── src/
├── inc/
└── README.md
```
## Flujo de trabajo

Para cada ejercicio:

1. Revisar el enunciado correspondiente.
2. Implementar la solución.
3. Comprobar que el programa compile correctamente.
4. Guardar los cambios con Git.
5. Realizar push al repositorio.
6. Revisar el resultado de la corrección automática en GitHub.
